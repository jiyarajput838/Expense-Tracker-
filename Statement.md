# Expense Tracker
# Project Title Expense Tracker

## 1. Problem Statement

People often spend money on food, travel, shopping, education, and other activities without maintaining proper records. Manual tracking can be time-consuming and may result in incorrect calculations.


## 2. Scope of the Project

The project focuses on developing a simple expense-management application.

The system includes:

- Adding daily expenses.
- Storing expense descriptions, categories, and amounts.
- Viewing all recorded expenses.
- Calculating total spending.
- Searching expenses by category.
- Deleting incorrect or unnecessary records.
- Displaying spending summaries.

The current version is a Java console application and stores data temporarily during execution. Future versions may include file storage, database connectivity, a graphical interface, and charts.

## 3. Target User

The application is designed for:

- Students managing daily expenses.
- Individuals tracking personal spending.
- Beginners learning Java programming.
- Small families monitoring household expenses.
- Users who want a simple budgeting tool.

The first version is mainly intended for individual users and academic demonstration purposes.

## 4. High-Level Features

- Add an expense with description, category, and amount.
- View all expenses in a list.
- Calculate total expense.
- Search expenses by category.
- Delete an expense.
- Validate empty and invalid inputs.
- Display error messages for incorrect values.
- Organize expenses into categories such as Food, Travel, Shopping, and Education.
- Support future budget and report generation features.

The application displays:

All expenses with their categories and amounts.
